# Participant headshots — 2025

Individual photos of each finalist team member. Square images (e.g. 400×400)
look best; they render in a circular avatar. Until a file is present, the
member's initials show automatically.

Placeholder filenames (team number, member number):

- team-1-member-1.jpg, team-1-member-2.jpg, team-1-member-3.jpg
- team-2-member-1.jpg, team-2-member-2.jpg, team-2-member-3.jpg
- team-3-member-1.jpg, team-3-member-2.jpg, team-3-member-3.jpg
- team-4-member-1.jpg, team-4-member-2.jpg, team-4-member-3.jpg
- team-5-member-1.jpg, team-5-member-2.jpg, team-5-member-3.jpg

Names, roles, and filenames are all set in `lib/edition-2025.ts`
(`finalistTeams[].members`). Add or remove members freely — each just needs a
`name`, an optional `role`, and an `image` path matching the file you drop here.
