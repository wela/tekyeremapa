# Brand logo

Drop the official Tɛkyerɛma Pa logo here as:

- logo.png — used in the home hero (transparent background, ideally ~640×768
  or larger; it displays up to 320px wide). SVG also works — if you add
  `logo.svg` instead, update the `src` in `components/home/Hero.tsx` to match.

Until this file exists, the hero shows a hand-drawn SVG approximation
(`components/shared/BrandShield.tsx`). Adding the file replaces it
automatically — no code change needed.
